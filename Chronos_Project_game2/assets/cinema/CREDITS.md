# Chronos cinematic environments

Four environments and one original character portrait generated for this game with the built-in imagegen tool, 1 November 2026. Original generated PNGs preserved; project copies are self-contained. No video model or external paid API used.

- `bridge.png`: ship bridge overlooking a damaged 2070 city; no baked interface.
- `anatolia-430.png`: an illustrative Anatolian river basin in 430 CE.
- `anatolia-dry.png`: the same composition on a damaged future trajectory.
- `anatolia-protected.png`: the same composition on a protected future trajectory.
- `researcher.png`: original field researcher portrait, transparent background; no real person is depicted.

These are fictional game illustrations, not historical evidence or forecasts. Future art blending is driven by the simulation's local water, soil and biodiversity; measured numbers remain separate from illustration.


## v0.9 narrative assets

Four further original AI illustrations generated with the built-in imagegen tool:
`cem.png` and `dara.png` are transparent portraits of fictional game characters;
`common-grazing.png` and `protected-boundary.png` illustrate two protection choices.
The people inside the wide illustrations are representative figures, not exact model-sheet matches to the named portraits. These depict possible actions, not guaranteed simulation outcomes. Full prompts: `STORY_PROMPTS.json`. No real person's likeness or historical testimony is claimed.

UI typography: Manrope (Manrope Project Authors) and Barlow Condensed (Barlow Project Authors), SIL Open Font License1.1. Font data, full licenses and source/hash manifest are bundled under `../fonts/`.

Motion/directing methodology reference: [Lemo-Opuscar DIRECTOR](https://github.com/lemomo-ai/lemo-opuscar/blob/main/DIRECTOR.md), [TECHNIQUE](https://github.com/lemomo-ai/lemo-opuscar/blob/main/TECHNIQUE.md) and [style grammar](https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/hd-2d/STYLE.md). This implementation uses our interactive DOM/SVG `actionFrame(time,kind)` and existing local game loop; no library render scripts, demo footage, browser capture pipeline or external paid voice service were installed or invoked.
